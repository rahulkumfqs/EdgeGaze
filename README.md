# EdgeGaze

EdgeGaze is a real-time data processing framework that leverages smart edge nodes for predictive analytics computations.

With EdgeGaze, you get a lightweight tool that stays out of your way.

**What you get**

- EdgeGaze is a real-time data
- processing framework that leverages smart
- edge nodes for predictive analytics

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/EdgeGaze.git`
2. `cd EdgeGaze`
3. Install in editable mode: `pip install -e .`

## Configuration

EdgeGaze is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
